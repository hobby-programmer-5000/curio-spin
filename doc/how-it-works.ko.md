# CurioSpin 동작 원리

CurioSpin이 하는 일은 네 가지입니다.

1. 공정하게 당첨 키워드를 뽑습니다.
2. 그 키워드에 멈추는 슬롯 릴 애니메이션을 보여 줍니다.
3. 비슷한 키워드가 릴에서 나란히 보이지 않도록 순서를 정합니다.
4. 지저분한 CSV/TXT 파일을 깔끔한 키워드 목록으로 바꿉니다.

모두 파이썬 표준 라이브러리만으로 구현했습니다. 머신러닝 모델, 임베딩, 네트워크 호출은 쓰지 않습니다. 로직은 [`core.py`](../core.py)에 있고 [`test_core.py`](../test_core.py)로 테스트합니다.

---

## 1. 추첨이 먼저다

릴이 움직이기 **전에** 당첨 키워드를 먼저 정합니다.

```python
winner = random.SystemRandom().choice(candidates)
```

`SystemRandom`은 운영체제의 암호학적 난수원을 쓰므로 모든 후보가 정확히 `1/n` 확률을 가집니다. 릴 순서(3장)는 그다음에 정해지고, 회전하는 동안 *보이는 것*에만 영향을 줍니다. 순서는 당첨 결과를 바꾸지 않으므로, 군집 방지 로직이 결과를 치우치게 할 수 없습니다.

## 2. 릴 애니메이션

릴은 키워드를 원형으로 이어 붙인 목록이고 Tk `Canvas`에 그립니다. 위치 `pos`는 실수인데, 정수 부분은 가운데 키워드의 번호이고 소수 부분은 스크롤 오프셋입니다. 화면에는 다섯 줄이 보이며, 글자는 가운데에서 멀어질수록 배경색 쪽으로 흐려집니다.

시작 위치 `p0`에서 번호 `t`의 당첨 키워드에 멈추려면:

```
Δ        = (t − p0) mod n                      # 한 바퀴 안에서 당첨까지 남은 거리
rows_min = 11 × 회전시간                        # 충분히 돌아가 보이도록
D        = Δ + n × ceil((rows_min − Δ) / n)    # 몇 바퀴 + Δ, 항상 rows_min 이상
```

정규화된 시간 `u ∈ [0, 1]`에 따른 위치는 감속(ease-out) 곡선에 마지막 작은 반동을 더한 것입니다.

```
pos(u) = p0 + D × (1 − (1 − u)^4)
       + 0.22 × sin(π × (u − 0.8) / 0.2)        u > 0.8 일 때만
```

`u = 1`에서 반동 항은 0이 되므로 `pos = p0 + D`가 정확히 당첨 키워드입니다. 프레임은 약 12 ms마다 그립니다.

## 3. 비슷한 키워드 떨어뜨리기

### 3.1 두 키워드의 유사도 (0 … 1)

먼저 키워드를 정규화합니다. 유니코드 NFKC 변환, 대소문자 통일, 폭 없는 문자 제거, 공백 정리를 합니다. 그다음 세 가지 특징을 만듭니다.

| 특징 | 예: `모차르트의 레퀴엠` | 잡아내는 것 |
|---|---|---|
| 구분자를 뺀 문자열의 글자 2-gram (`^`/`$` 경계 표시 포함) | `^모, 모차, 차르, …` | 철자 겹침 |
| **한글 자모** 3-gram: 음절을 유니코드 산술(`(코드 − 0xAC00) → 588, 28`)로 초성·중성·종성으로 분해 | `ㅁㅗㅊ, ㅗㅊㅏ, …` | 비슷한 한글 표기 (`강아지` / `강아쥐`) |
| 조사(`의 와 과 에서 …`)를 떼고 불용어를 뺀 단어(토큰) | `{모차르트, 레퀴엠}` | 조사나 어순이 달라도 같은 이름 공유 |

기본 점수는 가중합입니다.

```
기본 = 0.45 × Dice(2-gram) + 0.35 × Dice(자모 3-gram) + 0.20 × Jaccard(토큰)
```

여기에 구조 규칙이 점수를 끌어올릴 수 있습니다 (가장 큰 값을 씀).

| 규칙 | 점수 | 예 |
|---|---|---|
| 의미 있는 단어 공유 (한글 2자 이상, 라틴 4자 이상, 숫자만은 제외) | `0.45 + 0.35 × 단어길이 / 짧은쪽길이` | *모차르트의 레퀴엠* / *볼프강 아마데우스 모차르트* |
| 한쪽이 다른 쪽을 포함 | `0.55 + 0.45 × 짧은쪽 / 긴쪽` | *플라톤* / *플라톤의 동굴 우화* |
| 앞부분 2자 이상 같음 | `0.75 × 공통접두 / 짧은쪽길이` | `강아지사료` / `강아지간식` |
| 뒷부분 2자 이상 같음 | `0.60 × 공통접미 / 짧은쪽길이` | `강아지사료` / `고양이사료` |

조사는 떼고 나서 두 글자 이상 남을 때만, 그리고 명사의 끝 글자와 헷갈릴 일이 적은 것만 뗍니다. `의/와/과`는 떼지만 `은/는/이/가/로`는 떼지 않습니다(`피에로`가 `피에`가 되면 안 되므로).

**분야.** CSV에 분야/분류 열이 있으면 같은 분야 키워드끼리 유사도를 더합니다.

```
s' = s + (1 − s) × 0.35
```

그러면 같은 분야끼리 조금씩 밀어내고, 글자가 아주 비슷한 쌍은 여전히 가장 강하게 밀어냅니다.

### 3.2 릴 배열

릴은 원형이고, 한 키워드는 2~3칸 떨어진 이웃과 함께 화면에 보입니다. 그래서 순서 `o`의 비용을 이렇게 정의합니다.

```
cost(o) = Σ_i  Σ_{d=1..3}  w_d × sim(o_i, o_{(i+d) mod n}),    w = (1, 0.5, 0.25)
```

이 값을 정확히 최소화하는 건 순회 판매원 문제처럼 어려운 조합 문제입니다. 0.1초 단위로 충분히 좋은 답이면 되고, 결과가 **무작위**여야 하므로 두 단계로 찾습니다.

1. **무작위 탐욕 구성.** 임의의 키워드에서 시작합니다. 매 단계마다 남은 키워드 중 최대 `clamp(60000 / n, 4, 48)`개를 뽑아, 직전에 놓인 3개와의 가중 유사도로 점수를 매깁니다. 그리고 `최저 + 0.04` 안에 드는 후보 중에서 **무작위로** 하나를 고릅니다. 샘플링 덕분에 목록이 커도 빠르고, 무작위 선택 덕분에 매번 다른 순서가 나옵니다.
2. **무작위 교환 국소 탐색.** 임의의 두 칸을 바꾸고, 그 두 칸 주변의 쌍만 다시 계산합니다. 비용이 늘지 않으면 교환을 유지합니다. 최대 `40 × n`번 또는 시간 예산(앱에서는 0.15초)이 끝날 때까지 반복합니다. 비용이 같은 교환도 받아들이므로 순서가 계속 무작위로 흔들립니다.

매 회전마다 새 순서를 만들고, 지금 가운데에 보이는 키워드는 그 자리에 남도록 릴을 돌려 화면이 튀지 않게 합니다.

**361개 주제, 7개 분야 목록으로 측정한 결과:**

| | 그냥 섞기 | CurioSpin |
|---|---|---|
| 바로 옆 칸이 같은 분야 | 46번 | **0번** |
| 이웃한 키워드 간 최대 글자 유사도 | 0.62 | **0.00** |
| 7칸 간격으로 같은 분야 (고정 순환이면 ~100%) | 약 14% | 11% |

마지막 줄은 분야가 "역사 → 문학 → 미술…"처럼 예측 가능한 순서로 돌지 *않는다*는 뜻입니다. 키워드 3,000개 배열에 1초가 채 걸리지 않습니다.

## 4. CSV / TXT 전처리

### 디코딩
1. UTF-16 BOM이 있으면 UTF-16으로 읽습니다.
2. 아니면 UTF-8(BOM 있음/없음)을 시도합니다.
3. 다음으로 한글 엑셀이 "CSV"로 저장할 때 쓰는 CP949를 시도합니다.
4. 모두 실패하면 Latin-1(절대 실패하지 않음)로 읽습니다.

### 구분자
`csv.Sniffer`가 `,` `;` 탭 `|` 중에서 고릅니다. 판단하지 못하면 그중 가장 많이 나온 문자를 씁니다.

### 제목 행
처음 10행 안에서 빈 행과 셀 하나짜리 행을 건너뜁니다. 단, 보통 행이 두 칸 이상인 파일에서만 그렇게 합니다. "2026년 키워드 목록" 같은 제목으로 시작하는 파일을 처리하기 위해서입니다.

### 헤더 행
다음 중 하나에 해당하면 첫 행을 헤더로 봅니다.
- 셀이 알려진 열 이름과 맞을 때: *키워드, 주제, 이름*이나 *번호, id, 날짜, 개수, 분류, 분야* 같은 한국어·영어 이름입니다. 한국어 복합명사는 중심어가 뒤에 오므로 **가장 뒤에서 끝나는** 힌트를 씁니다. `검색 키워드`는 키워드 열이고 `키워드 검색량`은 키워드 열이 아닙니다.
- 텍스트 셀 아래 열의 값이 80% 이상 숫자·날짜·링크일 때.

### 키워드 열
- 헤더가 키워드 열처럼 보이는 열을 씁니다.
- 그런 열이 없으면 텍스트 위주 열(텍스트 60% 이상, 평균 길이 40 이하)을 씁니다. 이름이 번호·날짜·메모·분류처럼 보이는 열은 뺍니다.

### 분야 열
키워드 열이 아닌 열 중에서 다음 조건을 만족하면 분야 열로 씁니다.
- 이름이 분류 계열이거나(*분야, 분류, 카테고리, 장르, field, category …*),
- 값이 짧고(20자 이하) 텍스트 위주이면서 반복되는 열(서로 다른 값 수 ≤ 행 수의 ⅓).

### 필터
- 숫자나 날짜만 있는 값을 뺍니다.
- 헤더와 같은 값(반복된 헤더 행)을 뺍니다.
- 직접 지정한 단어를 뺍니다.
- NFKC + 대소문자 무시 비교로 중복을 없앱니다.

이 모든 추정은 가져오기 미리보기 창에 보이고, 가져오기 전에 바꿀 수 있습니다.

## 5. 포터블 구성

- PyInstaller `--onefile --windowed`로 만든 실행 파일 하나이며, 파이썬과 Tk가 안에 들어 있습니다.
- 상태(목록, 기록, 분야 정보, 언어, 옵션)는 exe 옆의 `keyword_slot_data.json`에 저장합니다. 그 폴더에 쓸 수 없으면 `%APPDATA%\CurioSpin\`에 저장합니다. 임시 파일에 먼저 쓴 뒤 교체하므로, 프로그램이 비정상 종료돼도 데이터 파일이 깨지지 않습니다.
- 고해상도(DPI)를 인식하며, 픽셀 크기는 모두 화면 DPI에 맞춰 조정됩니다.
